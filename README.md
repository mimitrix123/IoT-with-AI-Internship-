# IoT with AI Internship

A complete four-week internship portfolio covering embedded IoT, edge AI, cloud telemetry, computer vision, predictive maintenance, and smart-home automation.

## Projects

| Week | Project | Main technologies |
|---|---|---|
| 1 | Weather Monitoring Station | ESP32, DHT11, ThingSpeak |
| 2 | Predictive Maintenance | Python, pandas, scikit-learn, MQTT |
| 3 | AI Smart Doorbell | Raspberry Pi, camera, OpenCV, Python |
| 4 | AI Smart Home | ESP32/Raspberry Pi, sensors, MQTT, AI, dashboard |

## Repository structure

```text
Week-1-Weather-Monitoring-Station/
Week-2-Predictive-Maintenance/
Week-3-Smart-Doorbell/
Week-4-AI-Smart-Home/
```

Secrets such as Wi-Fi passwords, API keys, and tokens are excluded.

## Learning outcomes
- Build ESP32/Raspberry Pi IoT devices.
- Collect, validate, publish, and visualize sensor data.
- Train and evaluate practical machine-learning models.
- Add computer vision and edge-AI capabilities.
- Design MQTT device-to-cloud architectures.
- Apply automation, notifications, reliability, and basic security.

## Safety
Use isolated low-voltage electronics and appropriate power supplies. Never connect prototype GPIO pins directly to mains voltage.
