# Mobile Notifications

Notification events should be generated by the Raspberry Pi/edge service after validation, not directly by untrusted sensor payloads.

Example events:
- Occupancy detected while away mode is enabled
- Abnormal sound level sustained for a configured interval
- Sensor node offline
- Temperature above/below a configured threshold
- AI energy recommendation requiring user approval

Use a provider adapter (push notification, email or SMS) and keep API tokens in environment variables or a secret manager.
